# 🎃 Bhayanak Kahaniyan — Free Horror Story YouTube Automation

Generates a Hindi horror story **daily**, builds a full video **plus 2 YouTube Shorts** from the same story, and uploads everything to your YouTube channel — at **$0/month**.

## How it works

```
Story (AI)  ->  Images (AI)  ->  Voice (TTS)  ->  Full Video  ->  2 Shorts  ->  YouTube
```

| Step | Tool | Cost |
|------|------|------|
| Story generation | Gemini API free tier (Google AI Studio) *(on CI)* **or** local Ollama *(on your PC)* | Free |
| Images | Pollinations.ai image API (no key) | Free |
| Hindi voice | edge-tts (Microsoft neural voices, no key) | Free |
| Video + Shorts | MoviePy + FFmpeg | Free |
| YouTube upload | YouTube Data API v3 (free quota) | Free |
| Daily scheduling | GitHub Actions (2000 min/month free) | Free |

## Architecture

```
├── .github/workflows/daily_pipeline.yml   # Cron -> runs everything daily on GH Actions
├── src/
│   ├── config.py            # All settings from env vars
│   ├── story_generator.py   # Hindi horror story JSON (scenes + narration + image prompts)
│   ├── image_generator.py   # Downloads scene images (Pollinations)
│   ├── voice_generator.py   # Narration mp3s (edge-tts, hi-IN voices)
│   ├── video_maker.py       # Ken Burns + subtitles + bg music -> full video (9:16)
│   ├── short_maker.py       # 2 shorts cut from the full video
│   ├── youtube_uploader.py  # Uploads to YouTube
│   ├── auth_helper.py       # One-time OAuth -> refresh token
│   ├── pipeline.py          # Orchestrator (all steps in order)
│   └── utils.py
├── templates/story_prompt.txt            # The horror-writing prompt (edit freely)
├── assets/{bg_music,fonts,intro_outro}
└── output/{stories,images,audio,full_videos,shorts}
```

## 1. One-time YouTube setup (needed for auto-upload)

> Only if you want the daily auto-upload. You can also run everything locally and upload manually.

1. Go to **https://console.cloud.google.com** → create a project.
2. Enable **YouTube Data API v3** (APIs & Services → Library).
3. **OAuth consent screen** → set app type **External**, add scope:
   `https://www.googleapis.com/auth/youtube.upload`
4. **Credentials → Create Credentials → OAuth client ID → Desktop app**.
5. Copy the Client ID and Client Secret into `.env`:
   ```
   YOUTUBE_CLIENT_ID=xxxxxxxx.apps.googleusercontent.com
   YOUTUBE_CLIENT_SECRET=GOCSPX-...
   ```
6. Run the OAuth helper locally (needs Python):
   ```
   python src/auth_helper.py
   ```
   → Complete the browser flow → copy the printed **refresh token** into `.env`:
   ```
   YOUTUBE_REFRESH_TOKEN=1//0xxxxx...
   YOUTUBE_PRIVACY=private
   ```
7. Test uploads stay **private** first. Change `YOUTUBE_PRIVACY=public` whenever you're ready.

## 2. GitHub Actions setup (100% free daily automation)

1. Create a GitHub repo and push this folder.
2. Add **Secrets** (Settings → Secrets and variables → Actions):

   | Secret | Value |
   |--------|-------|
   | `GOOGLE_AI_API_KEY` | Free Gemini key from aistudio.google.com/apikey |
   | `YOUTUBE_CLIENT_ID` | from step 5 above |
   | `YOUTUBE_CLIENT_SECRET` | from step 5 above |
   | `YOUTUBE_REFRESH_TOKEN` | from step 6 above |
   | `FREE_BG_MUSIC_URI` *(optional)* | direct URL to a royalty-free horror mp3 |
   | `YOUTUBE_PRIVACY` *(variable, optional)* | `private` / `unlisted` / `public` |

3. The workflow runs every day at **06:15 IST** (`cron: "45 0 * * *"` in `daily_pipeline.yml` — edit to taste). You can also trigger manually from the **Actions** tab.
4. Finished videos are saved as **artifacts** for 7 days; the story JSON + manifest get committed back to the repo.

> ⚠️ The GitHub Runner **does not have Ollama**, so on CI the story is generated by **Gemini API free tier** (requires a free key — no charges, generous daily limit). Locally you can set `STORY_API_MODE=ollama` for higher-quality, unlimited Hindi storytelling.

1. Get a **free** Gemini API key at **https://aistudio.google.com/apikey** (zero cost, no credit card).
2. Add it as a secret named `GOOGLE_AI_API_KEY` alongside the YouTube secrets listed below.

## 3. Running locally

```
setup_locally.ps1     # installs deps (run once)
run_daily.ps1         # runs the whole pipeline today
```

Before local runs:
- Install **ffmpeg** (e.g. `winget install Gyan.FFmpeg`)
- (recommended) `ollama pull llama3.2` and set `STORY_API_MODE=ollama` in `.env`
- Drop a **Devanagari font** into `assets\fonts\` (e.g. copy `C:\Windows\Fonts\Nirmala.ttf`) — needed for burned-in subtitles
- Drop a **royalty-free horror mp3** into `assets\bg_music\` (the background music is mixed at low volume; without it the video will have narration only)

## 4. Customising the content

- **Story style / prompts / scenes** → edit `templates/story_prompt.txt` (it's the exact prompt sent to the LLM).
- **Voice** → change `VOICE_NAME` in config (e.g. `hi-IN-MadhurNeural`, `hi-IN-SwaraNeural`).
- **Pacing** → `VOICE_RATE=-10%` for a slower, creepier narration.
- **Video orientation** → `VIDEO_ORIENTATION=vertical` (Shorts, 1080×1920) or `horizontal` (1920×1080).
- **Number of shorts** → `SHORTS_PER_STORY` in `config.py`.
- **Upload time / frequency** → cron line in `.github/workflows/daily_pipeline.yml`. Add more cron rows to run 2×/day.

## 5. Costs & quotas

- **Money:** $0. GitHub Actions free tier = 2,000 minutes/month (~66/day); one run takes ~10–20 min.
- **Gemini free tier:** 30 req/min, 1500 req/day for gemini-2.0-flash — enough for 1 daily story.
- **YouTube quota:** a normal upload ≈ **1600 units** of the free 10,000/day → ~6 uploads/day possible (you use 3: one full + two shorts).
- **Pollinations images:** free tier — no key, generous daily usage.

## 6. Troubleshooting

| Symptom | Fix |
|---------|-----|
| `Missing YouTube credentials` | You skipped §1; upload is skipped, videos still built locally. |
| No subtitles on video | Put a Devanagari `.ttf` in `assets\fonts\`. |
| Story JSON parse error | Retry (transient LLM hiccup); tighten `templates/story_prompt.txt`. |
| Images blurred/dark | Edit prompts in `templates/story_prompt.txt`; adjust `model=flux` in `image_generator.py`. |
| Actions workflow times out | `timeout-minutes` is 55; a run is usually < 20 min. Increase to 80 max. |
